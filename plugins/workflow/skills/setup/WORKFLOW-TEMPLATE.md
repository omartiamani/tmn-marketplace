Copy this structure. Delete the sections that do not apply. Any unconfirmed value stays `TO BE DETERMINED`.

**Write the file in the language declared for the project's artifacts, headings included**: the headings below indicate the expected content, not their wording.

This file is read by humans. No technical identifier or command: they go into the "Workflow tooling" section of the `CLAUDE.md` (see [CLAUDE-TEMPLATE.md](./CLAUDE-TEMPLATE.md)). No absolute path, no personal account, no list of open points.
